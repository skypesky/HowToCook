## 油泼辣子

![口水鸡+油泼辣子](../../../dishes/condiment/油泼辣子/口水鸡+油泼辣子.jpg)
![油泼辣子](../../../dishes/condiment/油泼辣子/油泼辣子.jpg)

制作耗时约 10 分钟，预估烹饪难度：★★★。油泼辣子是许多中式菜肴的灵魂调料，香辣开胃，色泽红亮。

### 必备原料和工具

| 类别 | 名称 |
| :--- | :--- |
| **主要原料** | 蒜头, 干辣椒面, 盐, 熟白芝麻, 小米椒 |
| **液体调料** | 花生油（或菜籽油）, 白醋 |
| **香料 (可选)** | 五香粉, 草寇, 小葱, 八角, 花椒, 香叶, 白芷, 姜片 |
| **增味剂** | 糖 |
| **工具** | 家庭小陶瓷碗, 家庭铁勺子, 铁锅, 砧板 |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 蒜头 | 1 个 |
| 干辣椒面 | 100 克 |
| 盐 | 5 克 |
| 熟白芝麻 | 15 克 |
| 小米椒 | 1 个 |
| 花生油 | 150 毫升 |
| 五香粉 | 10 克（可选） |
| 草寇 | 1 个（可选） |
| 小葱 | 3-5 根（可选） |
| 其他配料 | 八角(1), 花椒(20-50粒), 香叶(2-3片), 白芷(2-3片), 姜片 |
| 糖 | 30 克 |
| 白醋 | 5 毫升 |

### 操作

1.  取 2 个小蒜头去皮，和 1 个小米椒一同剁碎备用。
2.  在锅中倒入花生油，放入八角、花椒、香叶、白芷、姜片和小葱，用中火加热，待香料炸至焦黄，捞出弃用，得到香料油。
3.  将香料油加热至约 210°C（若为菜籽油，需烧至冒烟）。
4.  在耐热的陶瓷碗中，混合干辣椒面、熟白芝麻、蒜末、小米椒末、盐、五香粉和草寇。
5.  关火，将热油分次倒入调料碗中，边倒边用勺子搅拌，激发香味。
6.  稍作搅拌后放入白醋，此时油会重新沸腾，继续搅拌，白醋可以增添复合香气。
7.  待油泼辣子冷却至温热后，放入白糖，搅拌均匀。白糖可以使辣味变得柔和，不那么呛口。

### 附加内容

-   加入五香粉、草寇等香料可以使油泼辣子的香味层次更丰富。
-   为了追求更刺激的辣度，可以在油温降至 165°C 时，再加入另一份等量的干辣椒面等调料进行混合。

## 草莓酱

将时令草莓制成甜美的果酱，是搭配面包、酸奶或冰淇淋的绝佳选择。此配方操作简单，能最大程度保留草莓的自然风味。

预估烹饪难度：★★

### 必备原料和工具

| 原料 | 工具 |
| :--- | :--- |
| 草莓 | 碗 |
| 白砂糖 | 不粘锅 |
| 保鲜膜 | 可密封的罐子 |

### 计算

| 原料 | 用量 | 备注 |
| :--- | :--- | :--- |
| 草莓 | 1200 克 | |
| 白糖 | 400 克 | 如需低糖饮食，可减至 200克。 |

### 操作

1.  将草莓洗净、去蒂，然后切成小块放入碗中。
2.  将白砂糖倒入碗中，与草莓碎块充分搅拌均匀。
3.  用保鲜膜封住碗口，在室温下静置 1 小时，让草莓出汁并与糖融合。
4.  将静置后的草莓和糖的混合物全部倒入不粘锅中，开大火煮沸。
5.  煮沸后转为小火，持续不断地搅拌，防止粘锅，直到果酱整体变得粘稠。
6.  关火后，待草莓酱完全冷却，再将其装入事先准备好的洁净、干燥的密封罐中，放入冰箱冷藏保存。

## 蔗糖糖浆

预先制作好糖浆，可以极大地提升调制饮品（特别是冷饮）的效率和一致性。

预估烹饪难度：★

### 必备原料和工具

| 原料 | 工具 |
| :--- | :--- |
| 白砂糖 | 可密封容器（推荐使用高硼硅试剂瓶） |
| 水 | |

### 计算

推荐采用 **糖:水 = 1:1** 的重量比例，这样便于精确控制用糖量。例如，需要 15 克糖时，量取 30 克糖浆即可。

| 原料 | 用量 |
| :--- | :--- |
| 水 | 100 克 |
| 白砂糖 | 100 克 |

### 操作

1.  将称量好的白砂糖和饮用水在容器中混合均匀。
2.  盖紧容器封盖，放入冰箱冷藏保存。

### 附加内容

-   使用冷水或热水均可。若急用，可使用热水以加速溶解，待糖浆冷却后再使用。
-   配制好的糖浆性质稳定，不易变质，在冰箱冷藏条件下通常可以安全保存一周。

## 油酥

油酥是制作中式酥皮点心和烙饼的关键材料，由面粉与热油混合而成。在烙饼时涂抹一层油酥，能使成品层次分明，口感外酥里软。

预估烹饪难度：★★

### 必备原料和工具

| 原料 | 工具 |
| :--- | :--- |
| 面粉 | 小碗 |
| 油 | 筷子 |
| 盐 | |

### 计算

用量可根据要制作的饼的数量进行调整：

| 原料 | 计算公式 |
| :--- | :--- |
| 油 | 烙饼张数 × 10ml |
| 盐 | 烙饼张数 / 2 (克) |
| 面粉 | 烙饼张数 / 0.13 (克) |

### 操作

1.  将面粉和盐一同放入小碗中。
2.  将油加热至约 200°C 的高温状态。
3.  将热油迅速倒入面粉中，同时用筷子快速搅拌，直至形成没有干面粉颗粒的均匀糊状。

## 炸串酱料

号称“淋袜子都好吃”的万能炸串酱料，制作简单，新手友好，能为各种炸物增添风味。

预计用时 10 分钟，预估烹饪难度：★★。

### 必备原料和工具

| 原料 |
| :--- |
| 干辣椒面（粗、细两种） |
| 孜然粉 |
| 胡椒粉 |
| 五香粉 |
| 花椒粉 |
| 十三香 |
| 麻辣鲜 |
| 白芝麻 |
| 食盐 |
| 鸡精 |
| 香油, 生抽, 花椒油, 蚝油 |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 干辣椒面 | 60 克 |
| 孜然粉 | 20 克 |
| 胡椒粉 | 10 克 |
| 五香粉 | 15 克 |
| 食盐 | 20 克 |
| 花椒粉 | 15 克 |
| 鸡精 | 8 克 |
| 十三香 | 5 克 |
| 麻辣鲜 | 5 克 |
| 白芝麻 | 30 克 |

### 操作

1.  将所有干性原料（辣椒面、孜然粉、胡椒粉等）在耐热容器内混合，搅拌均匀。
2.  锅中烧热油，油量以能浸没容器中所有原材料为佳。
3.  将热油分三次淋入原料中，每次淋入三分之一后立即用筷子或勺子搅拌均匀，以防炸糊并充分激发香味。
4.  待油温稍降后，加入香油 10ml、生抽 10ml、花椒油 10ml 和蚝油 10ml，再次搅拌均匀即可。

### 附加内容

-   最后一步的液体调味料可根据个人口味偏好进行调整或增减。
-   **关键步骤**：必须分次淋入热油并搅拌，切勿一次性全部倒入。
-   所有原料可根据需求按比例增减。

## 简易版炒糖色

炒糖色是许多红烧类菜肴上色的关键步骤。本指南提供一个简易版本，适合初学者。若想学习更深入的技巧，可以探索更为专业的烹饪教程。

预估烹饪难度：★★★★

### 必备原料和工具

| 原料 |
| :--- |
| 糖（冰糖、白砂糖或绵白糖） |
| 油 |
| 开水 |

**注意事项**：
-   炒糖色过程中**火力不宜过大**。
-   使用冰糖或白砂糖时，推荐采用水油法，因为它们不加水融化很慢。
-   绵白糖吸湿性好，可以不加水直接油炒。

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 油 | 100ml |
| 开水 | 500ml |
| 糖 | 约 100-150g（以冰糖为例） |

### 操作

1.  开中大火，向锅中迅速倒入 100ml 开水和 100ml 油。
2.  放入糖（若是大块冰糖，建议提前敲碎以加速融化）。
3.  转为中火，用锅铲**持续不断地搅拌**。
4.  当糖液开始变成棕褐色时，**立即转为小火**。
5.  继续搅拌，糖液颜色会先变稀，呈现红茶色，然后加深至酱红色并开始冒起细小的泡泡。
6.  小泡会逐渐转为大气泡，当大气泡出现时，糖色即完成。此时必须**迅速进行下一步**，否则火候稍过糖色便会发苦。
    -   **操作1（制作糖色水）**：立即沿锅边加入 400ml 开水降温，制成可储存的糖色水。
    -   **操作2（直接用于烹饪）**：直接下入需要上色的食材（如焯好水的肉块）或葱姜蒜等调味品进行快速翻炒。

## 糖醋汁

掌握经典的糖醋汁比例，轻松复刻糖醋鱼、糖醋里脊、糖醋排骨等酸甜口味的菜肴。

预估烹饪难度：★★

### 必备原料和工具

| 原料 |
| :--- |
| 料酒 |
| 生抽 |
| 白糖 |
| 白醋或米醋 |
| 清水 |

### 计算（经典比例 1:2:3:4:5）

此比例指的是 **料酒:醋:糖:酱油:水** 的体积或重量份数。

| 原料 | 用量（参考） | 份数 |
| :--- | :--- | :--- |
| 料酒 | 10ml | 1 份 |
| 白醋/米醋 | 20ml | 2 份 |
| 白糖 | 30g | 3 份 |
| 生抽 | 40ml | 4 份 |
| 清水 | 50ml | 5 份 |

### 操作

1.  按照上述比例，将所有调料在小碗中混合并搅拌均匀。
2.  在菜肴烹饪的最后阶段，将配制好的糖醋汁倒入锅中。
3.  根据具体菜肴的需求，与食材一同烹煮 5-10 分钟。
4.  最后开大火收汁，使汤汁变得浓稠，均匀地包裹在食材上，增加菜肴的色泽和风味。

## 葱油

葱油是用热油萃取葱及其他香辛料的香味制成的调味油，可用于凉拌菜、调制肉馅，或在热炒菜出锅前淋入作为明油，提亮增香。

预估烹饪难度：★★★

### 必备原料和工具

| 原料 |
| :--- |
| 油 |
| 葱（大葱、小葱均可） |
| 姜 |
| 洋葱 |
| 料酒 |
| 香菜（可选） |
| 开洋（即虾米，可选） |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 油 | 200g |
| 葱 | 80g |
| 姜 | 20g |
| 洋葱 | 150g |
| 开洋 | 50g（可选） |
| 料酒 | 10ml（用于浸泡开洋） |

### 操作

1.  **预处理开洋**：将开洋放入 50°C 温水中，加入 10ml 料酒浸泡 10 分钟以去除腥味，然后捞出沥干水分。
2.  **预处理蔬菜**：葱和香菜洗净，切成约 5cm 长的段，并擦干表面水分。洋葱切丝，放入沸水中煮 5 分钟后捞出沥干。姜去皮切片。
3.  **熬制葱油**：锅中倒入全部的油，冷油时即放入所有预处理好的材料（葱、姜、洋葱、开洋等）。
4.  开中小火，慢炸约 20 分钟，直到所有香料变得干香、颜色金黄。
5.  关火后，即可得到葱香四溢的葱油。

### 附加内容

-   开洋能极大地提升葱油的鲜香层次感和鲜甜风味，强烈推荐使用。
-   熬制后的葱、姜、开洋等料渣可以根据喜好选择滤掉，也可以保留在油中一同食用。

## 蒜香酱油

一款制作极其简单的快手蘸料，蒜香浓郁，适合搭配饺子、白切肉等多种食物。

预估烹饪难度：★★

### 必备原料和工具

| 原料 | 工具 |
| :--- | :--- |
| 蒜头 | 蘸料碟 |
| 酱油 | 小锅 |
| 花生油 | 筷子 |
| 白芝麻（可选） | |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 蒜头 | 2 瓣 |
| 酱油 | 30 毫升 |
| 花生油 | 15 毫升 |
| 白芝麻 | 5 克（可选） |
| 蘸料碟 | 1 个 |

### 操作

1.  将蒜头拍碎或切成蒜末。
2.  在蘸料碟中倒入酱油，可根据喜好加入白芝麻。
3.  在小锅中加入花生油，加热至油温滚烫（约七八成热）。
4.  下入蒜末，快速炸约 15-30 秒，炸出香味。
5.  关火，立即将热油和蒜末一同倒入酱油碟中，用筷子搅拌均匀即可。
