## 油泼辣子

![油泼辣子](../../../dishes/condiment/油泼辣子/油泼辣子.jpg)
![口水鸡+油泼辣子](../../../dishes/condiment/油泼辣子/口水鸡+油泼辣子.jpg)

- **制作耗时**：10 分钟
- **预估烹饪难度**：★★★

### 必备原料和工具

| 原料/工具 | 数量 | 备注 |
| :--- | :--- | :--- |
| 蒜头 | 1 个 | |
| 干辣椒面 | 100 克 | |
| 盐 | 5 克 | |
| 熟白芝麻 | 15 克 | |
| 小米椒 | 1 个 | |
| 花生油 | 150 毫升 | 可用菜籽油替换 |
| 五香粉 | 10 克 | 可选 |
| 草寇 | 1 个 | 可选 |
| 小葱 | 3-5 根 | 可选 |
| 八角 | 1 个 | |
| 花椒 | 20-50 粒 | 根据个人口味调整 |
| 香叶 | 2-3 片 | |
| 白芷 | 2-3 片 | |
| 姜片 | 适量 | 可选，大拇指粗细的姜切片 |
| 糖 | 30 克 | |
| 白醋 | 5 毫升 | 约一小铁勺 |
| 小陶瓷碗 | 1 个 | |
| 铁勺 | 1 个 | |
| 铁锅 | 1 个 | |

### 操作

1.  取 2 瓣小蒜头去皮，和小米椒一同剁碎。
2.  在锅中倒入花生油，放入八角、花椒、香叶、白芷、姜片和小葱。
3.  开火加热，待香料变焦后，将其捞出弃用。
4.  将油继续加热 2 分钟（若用菜籽油，则烧至冒烟）。
5.  在干净的陶瓷碗中，加入干辣椒面、白芝麻、蒜末、小米椒末、盐、五香粉和草寇。
6.  关火，待油温冷却至约 210°C。
7.  将热油分次倒入碗中，并用勺子不断搅拌。
8.  倒入热油搅拌后，加入白醋，此时会重新沸腾，继续搅拌以增香。
9.  待油泼辣子冷却至温热，放入白糖和味精，搅拌均匀。白糖可以使辣味更柔和。

### 附加内容

- 在调料中加入五香粉和草寇可以增加复合香味，使油泼辣子味道更浓郁。

## 草莓酱

可以买那种一筐一筐卖的小草莓，主要是便宜。做成酱抹在面包上非常好吃。

- **预估烹饪难度**：★★

![洗好的草莓](../../../dishes/condiment/草莓酱/洗好的草莓.jpeg)
![混合好的草莓](../../../dishes/condiment/草莓酱/混合好的草莓.jpeg)
![熬煮的草莓](../../../dishes/condiment/草莓酱/熬煮的草莓.jpeg)
![做好的草莓酱](../../../dishes/condiment/草莓酱/做好的草莓酱.png)

### 必备原料和工具

| 原料/工具 | 数量 | 备注 |
| :--- | :--- | :--- |
| 草莓 | 1200 克 | |
| 白砂糖 | 400 克 | 可根据口味降至 200 克 |
| 保鲜膜 | 适量 | |
| 不粘锅 | 1 个 | |
| 密封罐 | 1 个 | |

### 操作

1.  将草莓洗净去叶，然后切碎放入一个合适的碗中。
2.  将白糖倒入碗中，与草莓搅拌均匀。
3.  用保鲜膜覆盖碗口，静置 1 小时，让草莓出汁。
4.  将混合物倒入不粘锅中，开大火烧开。
5.  烧开后转为小火，不断搅拌，直至果酱呈粘稠状后关火。
6.  待草莓酱完全冷却后，装入准备好的密封罐中保存。

## 蔗糖糖浆

将糖事先溶解好，便于在配制饮料（特别是冷饮）时为饮料增甜。

- **预估烹饪难度**：★

![bottle](../../../dishes/condiment/蔗糖糖浆/bottle.jpg)

### 必备原料和工具

| 原料/工具 | 数量 | 备注 |
| :--- | :--- | :--- |
| 白砂糖 | 100 克 | |
| 水 | 100 克 | 建议糖水比例 1:1 |
| 可密封容器 | 1 个 | 建议使用高硼硅试剂瓶 |

### 操作

1.  将称量好的白砂糖和饮用水在容器中混合均匀。
2.  将容器封盖后，放入冰箱冷藏保存。

### 附加内容

- 水无论冷热均可。如果急用，可先用热水溶解，待糖浆冷却后再使用。
- 配制好的糖浆在冷藏状态下可保存一周左右。

## 油酥

油酥由面粉与热油混合调制而成，通常在烙饼时涂抹，可以使饼层次分明，外酥里软。

- **预估烹饪难度**：★★

### 必备原料和工具

| 原料/工具 | 数量 | 备注 |
| :--- | :--- | :--- |
| 面粉 | (烙饼张数 / 0.13) 克 | |
| 油 | (烙饼张数 * 10) 毫升 | |
| 盐 | (烙饼张数 / 2) 克 | |

### 操作

1.  将面粉和盐盛在小碗中。
2.  将油加热至约 200°C，倒入碗中。
3.  用筷子迅速搅拌，直至成为没有干粉颗粒的糊状即可。

## 炸串酱料

炸串酱料，号称淋袜子都好吃，新手友好。

- **制作耗时**：10 分钟
- **预估烹饪难度**：★★

### 必备原料和工具

| 原料 | 数量 |
| :--- | :--- |
| 干辣椒面 | 60 克 |
| 孜然粉 | 20 克 |
| 胡椒粉 | 10 克 |
| 五香粉 | 15 克 |
| 食盐 | 20 克 |
| 花椒粉 | 15 克 |
| 鸡精 | 8 克 |
| 十三香 | 5 克 |
| 麻辣鲜 | 5 克 |
| 白芝麻 | 30 克 |
| 香油 | 10 毫升 |
| 生抽 | 10 毫升 |
| 花椒油 | 10 毫升 |
| 蚝油 | 10 毫升 |
| 食用油 | 适量 |

### 操作

1.  将除液体调料外的所有粉状和颗粒状原料在容器内混合，搅拌均匀。
2.  锅里烧热油，油量以能没过容器内所有原材料为佳。
3.  将热油分三次淋入容器，每次淋入后都要充分搅拌。
4.  最后放入香油、生抽、花椒油和蚝油，搅拌均匀即可。

### 附加内容

- 最后一步的液体调味料可根据个人喜好调整。
- 必须分次倒入热油并搅拌，不得一次性全部倒入。
- 所有原料可按比例增减。

## 简易版炒糖色

这是简易的糖色做法。对于更为进阶的技巧，请参考相关高级烹饪指南。

- **预估烹饪难度**：★★★★

### 必备原料和工具

| 原料/工具 | 数量 | 备注 |
| :--- | :--- | :--- |
| 糖 | 适量 | 冰糖、白砂糖或绵白糖均可 |
| 油 | 100 毫升 | |
| 开水 | 500 毫升 | |
| 锅 | 1 个 | |

### 操作

**注意：炒糖色全程火候控制是关键，火不要太大。**

1.  开火，向锅中倒入 100 毫升开水，随即倒入 100 毫升油。
2.  放入糖（若用冰糖，建议提前敲碎）。
3.  调整为中火，并持续搅拌。
4.  当糖液变成棕褐色时，转为小火，继续搅拌。
5.  糖液会先变稀，颜色变为红茶色，再变为酱红色并开始冒小泡。
6.  小泡逐渐消失后，会出现大泡，此时糖色完成。必须立刻进行下一步。
7.  根据需要选择操作：
    - **操作 1**：快速加入剩余的 400 毫升开水降温，制成糖色汁。
    - **操作 2**：加入葱、姜、蒜等调味品进行翻炒，用于烹饪。

## 糖醋汁

糖醋汁可用于糖醋鱼、糖醋里脊、糖醋排骨等菜品的制作。可依据经典比例 1:2:3:4:5（料酒:白醋:白糖:生抽:清水）来调制。

- **预估烹饪难度**：★★

### 必备原料和工具

| 原料 | 份量（按比例） | 示例用量 |
| :--- | :--- | :--- |
| 料酒 | 1 份 | 10 毫升 |
| 白醋/米醋 | 2 份 | 20 毫升 |
| 白糖 | 3 份 | 30 克 |
| 生抽 | 4 份 | 40 毫升 |
| 清水 | 5 份 | 50 毫升 |

### 操作

1.  按照比例将所有调料在小碗中混合，搅拌均匀。
2.  在菜肴烹饪的最后阶段，将配制好的糖醋汁倒入锅中。
3.  根据菜肴情况，继续烹制 5-10 分钟。
4.  最后开大火收汁，使汤汁浓稠，即可出锅。

## 葱油

葱油是用热油萃取以葱为主的各类香辛料得到的产物，可以用来调制肉馅、做凉拌菜或在热炒菜中作为出锅明油使用。

- **预估烹饪难度**：★★★

### 必备原料和工具

| 原料 | 数量 |
| :--- | :--- |
| 油 | 200 克 |
| 葱 | 80 克 |
| 姜 | 20 克 |
| 料酒 | 10 毫升 |
| 洋葱 | 150 克 |
| 开洋（虾米） | 50 克 |
| 香菜 | 适量（可选） |

### 操作

1.  将开洋（虾米）泡入 50°C 温水中，加入 10 毫升料酒去腥，浸泡 10 分钟后取出沥干。
2.  葱和香菜洗净，切成 5 厘米长的段，并擦干表面水分。
3.  洋葱切丝，在沸水中煮 5 分钟，捞出沥干水分。
4.  姜去皮，切成片。
5.  锅中倒入全部油，放入所有预处理好的材料，开中小火慢炸约 20 分钟，直到香料变干变黄。
6.  关火，滤掉料渣即可得到葱油。

### 附加内容

- 炸后的开洋和葱渣也可以食用。
- 开洋可以极大提升葱油的鲜香和甜味。

## 蒜香酱油

- **预估烹饪难度**：★★

### 必备原料和工具

| 原料/工具 | 数量 |
| :--- | :--- |
| 蒜头 | 2 瓣 |
| 白芝麻 | 5 克 |
| 花生油 | 15 毫升 |
| 酱油 | 30 毫升 |
| 蘸料碟 | 1 个 |

### 操作

1.  将蒜头拍碎。
2.  在蘸料碟中倒入酱油和白芝麻。
3.  起锅烧油，待油温升高后放入拍好的蒜头，炸半分钟出香味。
4.  关火，立即将蒜头热油倒入蘸料碟中，搅拌均匀即可。
