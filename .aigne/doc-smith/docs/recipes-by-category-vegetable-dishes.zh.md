<h2 id="上汤娃娃菜">上汤娃娃菜</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 娃娃菜 | 700g |
| 金针菇 | 10g (可选) |
| 皮蛋 | 1个 (可选) |
| 午餐肉/火腿肠 | 适量 |
| 葱 | 3g |
| 姜 | 10g |
| 蒜 | 10g |
| 盐 | 适量 |
| 糖 | 适量 |
| 蚝油 | 适量 |
| 味精 | 适量 |
| 淀粉 | 适量 |

### 操作步骤

1.  娃娃菜洗净，竖向切成段。
2.  葱切小段，蒜切片，姜切小片。
3.  皮蛋和午餐肉（或火腿肠）切成约1cm大小的丁。
4.  金针菇洗净撕开。
5.  锅中烧热水，将娃娃菜放入焯烫十秒钟后捞出。
6.  热锅凉油：先将锅烧热，倒入油滑锅后倒出，再重新倒入少量油。
7.  调至小火，加入葱、姜、蒜，煎炒出香味。
8.  加入约300g清水（水量以没过娃娃菜为宜），放入娃娃菜、金针菇和午餐肉丁。
9.  加入蚝油、糖、盐、味精等调味料，大火烧开。
10. 持续煮3分钟，待汤汁煮开后，先将娃娃菜和金针菇盛出装盘。
11. 将皮蛋丁放在菜上，然后把锅内剩余的汤汁浇上即可。

<h2 id="包菜炒鸡蛋粉丝">包菜炒鸡蛋粉丝</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 包菜 | 半颗 |
| 鸡蛋 | 2个 |
| 粉丝 | 1把 |
| 胡萝卜 | 半根 |
| 菜籽油 | 20ml |
| 盐 | 2g |
| 生抽 | 15ml |
| 老抽 | 10ml |
| 蚝油 | 10ml |
| 葱 | 半根 |
| 蒜 | 2瓣 |
| 干辣椒 | 5根 |

### 操作步骤

1.  胡萝卜、包菜切丝备用。
2.  粉丝用冷水浸泡1小时，然后放入开水中烫软，捞出备用。
3.  鸡蛋打入碗中，加入少许盐，搅拌15秒。
4.  葱、蒜、干辣椒切成小粒备用。
5.  起锅烧油，倒入蛋液，炒熟打散后盛出。
6.  锅中再次倒油，放入葱、蒜、干辣椒翻炒约8秒爆香。
7.  下入胡萝卜丝和包菜丝，翻炒30秒。
8.  放入处理好的粉丝。
9.  加入调料：生抽15ml，老抽10ml，蚝油10ml，盐2g。
10. 放入之前炒好的鸡蛋，继续翻炒约15秒。
11. 翻炒均匀后即可出锅摆盘。

<h2 id="地三鲜">地三鲜</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 (2-4人份) |
| :--- | :--- |
| 茄子 | 100g |
| 土豆 | 150g |
| 尖椒 | 3-4个 |
| 葱 | 3g |
| 姜 | 10g |
| 蒜 | 10g |
| 豆瓣酱 | 20ml |
| 生抽 | 10ml |
| 盐 | 8g |
| 糖 | 10g |
| 淀粉 | 20g |
| 食用油 | 25ml (+15ml备用) |
| 水 | 200ml |

### 操作步骤

1.  土豆洗净去皮，茄子、尖椒洗净。
2.  葱切成0.5cm小段，蒜剁碎，姜切末。
3.  茄子、土豆、尖椒均切成约15g的小块。
4.  热锅中加入25ml油。
5.  下入土豆块，煎炸约3分钟，至八分熟，表面呈金黄色后捞出。
6.  利用锅中底油，下入茄子块，煎炸约40秒，至七分熟，表面金黄。
7.  若锅内油量不足，可补充15ml油。
8.  放入葱、姜爆香。
9.  加入豆瓣酱、生抽、盐、糖，翻炒均匀。
10. 放入之前处理好的土豆和尖椒，翻炒1分钟。
11. 加入蒜末。
12. 倒入200ml水与20g淀粉混合的芡汁。
13. 待水开后，汤汁减少一半时，即可关火盛盘。

<h2 id="干锅花菜">干锅花菜</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 花菜 | 400g |
| 五花肉 | 100g |
| 辣椒 | 1-2根 |
| 生抽 | 10ml |
| 白糖 | 5g |
| 蒜 | 3-4瓣 |
| 盐 | 2g |
| 油 | 10ml |

### 操作步骤

1.  花菜浸泡在淡盐水中20分钟，洗净后拆成小朵。
2.  将花菜放入开水锅中焯水1分钟，捞出后立即用冷水冲凉，沥干备用。
3.  五花肉切薄片，大蒜拍扁，小红辣椒切段。
4.  锅烧热放油，下大葱白爆香。
5.  下五花肉片，中火煸炒至表面变色，并逼出部分油脂。
6.  倒入红辣椒段和花菜，翻炒几下。
7.  加入10ml生抽和5g白糖，转大火不断翻炒1分钟。
8.  放入大蒜叶段，翻炒几下后，关火盖上盖子焖1分钟即可。

<h2 id="手撕包菜">手撕包菜</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 包菜 | 1颗 |
| 五花肉 | 200g |
| 小米辣 | 2根 |
| 食用油 | 60ml |
| 料酒 | 5ml |
| 生抽 | 5ml |
| 香醋 | 5ml |
| 鸡精 | 2g |
| 姜 | 2片 |
| 蒜头 | 2粒 |
| 蒜苗 | 0.5根 |
| 盐 | 5g |

### 操作步骤

1.  包菜对半切开，去掉中间硬芯，用手撕成小块。
2.  用2g盐清洗包菜并沥干水分。
3.  姜、蒜、小米辣、蒜苗处理好备用。
4.  五花肉切片洗净备用。
5.  锅中加入30ml油，大火翻炒包菜1分钟，加3g盐，继续翻炒2分钟至七分熟后盛出。
6.  锅中再加30ml油，倒入五花肉，大火翻炒1分钟。
7.  倒入姜蒜等配料，翻炒1分钟。
8.  倒入包菜，加入香醋、料酒、鸡精、生抽，大火继续翻炒2分钟即可出锅。

<h2 id="拔丝土豆">拔丝土豆</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 土豆 | 2个 |
| 食用油 | 约300ml |
| 淀粉 | 30g |
| 白砂糖 | 120g |
| 水 | 100ml |
| 芝麻 | 5g |

### 操作步骤

1.  土豆去皮，切成均匀的小块，裹上干淀粉。
2.  起锅烧油，油量需能没过土豆。放入土豆块，煎炸5-7分钟，直至筷子可以轻松插入。
3.  捞出炸好的土豆备用。
4.  锅中留底油，加入水和白砂糖，沿一个方向慢慢搅动，熬至糖浆颜色变成褐色。
5.  倒入炸好的土豆，快速翻炒30秒，使糖浆均匀裹在土豆上。
6.  出锅盛盘，撒上芝麻即可。

<h2 id="椒盐玉米">椒盐玉米</h2>

**预估烹饪难度**：★★★

### 必备原料与工具

| 原料/工具 | 建议用量 |
| :--- | :--- |
| 袋装玉米粒 | 350g |
| 淀粉 | 40-70g |
| 椒盐粉 | 10g |
| 芝麻粒 | 10g |
| 油 | 适量 |

### 操作步骤

1.  将袋装玉米粒解冻（可用温水浸泡15分钟或带包装煮5分钟）。
2.  用吸油纸或簸箕多次操作，吸干玉米粒表面水分，但保持湿润。
3.  倒入足量淀粉，摇晃簸箕使玉米粒均匀裹上淀粉。
4.  锅中倒油铺满锅底，油热至八成时，倒入裹好淀粉的玉米粒。
5.  中火先煎30秒，不要翻动，让淀粉定型。

2.  加入糖或盐，略微搅匀。
3.  准备100℃的沸水。
4.  一边用筷子快速搅拌蛋液，一边将沸水以细流状冲入。
5.  持续搅拌，直至蛋液被完全烫熟，形成均匀蛋花。
