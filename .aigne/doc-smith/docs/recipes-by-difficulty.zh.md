# 按难度索引

本章节根据菜谱的烹饪难度进行分类，从一星到五星，难度依次递增。您可以根据自己的烹饪水平和时间安排，选择合适的菜谱进行尝试。星级越高，意味着菜谱的步骤越复杂、对技巧和时间的要求也越高。
