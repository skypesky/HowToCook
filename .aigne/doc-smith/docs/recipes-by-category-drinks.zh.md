# 饮料

本部分汇集了多款自制饮品的详细做法，无论您是想在炎热的夏日里寻找一丝清凉，还是希望在寒冷的冬日里感受一份温暖，亦或是在聚会中为朋友们调制一杯惊艳的特饮，这里都有合适的选择。内容涵盖了从传统中式饮品到现代创意特调，从无酒精的健康果蔬汁到微醺的鸡尾酒，每份食谱都提供了清晰的步骤和精确的配料用量，旨在帮助您轻松复刻美味。

## 无酒精特调

本节包含所有不含酒精的饮品，适合所有年龄段的人群享用。

### 冰粉

石凉粉，在部分地区也称作冰粉，是一种著名的特色小吃。该菜品类似果冻，但因其由天然植物制成，所以更为健康。配上薄荷汁、柠檬汁或红豆等调料，清凉解暑。

![石凉粉(冰粉)成品1](../../../dishes/drink/冰粉/石凉粉(冰粉)成品1.jpg)

**预估烹饪难度**：★★

#### 必备原料和工具

| 原料/工具 | 数量/规格 |
| :--- | :--- |
| 冰粉籽 | 200g |
| 过滤用纱布 | 一块 |
| 凉白开 | 2000g |
| 薄荷汁或薄荷粉 | 10ml 或 10g |
| 一次性塑料杯 | 可选 |
| 遇水发光冰块 | 可选 |

#### 计算

每份可供 5 人食用。

#### 操作

1.  将 2000g 凉白开倒入盆中。
2.  将 200g 冰粉籽用纱布完全包裹，并打结封口。
3.  将包好的冰粉籽放入凉白开中，用力揉搓 6 分钟。
4.  将揉搓后的液体静置 2.5 小时，直至其自然成型。
5.  将成型的冰粉用勺子装入杯中，加入 10ml 薄荷汁或 10g 薄荷粉（也可使用柠檬汁、山楂汁等）。
6.  加入遇水发光冰块（可选），并用勺子搅拌均匀。

#### 附加内容

-   操作时需注意观察液体的颜色和粘度。如颜色过浅或液体不黏稠，可能表示冰粉籽用量不足或揉搓时间与力度不够。

### 奇异果菠菜特调

本品为仿照宜家同款饮品研制，口感清爽。

![奇异果菠菜特调](../../../dishes/drink/奇异果菠菜特调/kiwi-example.jpg)

**预估烹饪难度**：★

#### 必备原料和工具

-   **原料**: 奇异果、苹果、菠菜叶、水、白砂糖
-   **工具**: 榨汁机

#### 计算

| 原料 | 用量 |
| :--- | :--- |
| 饮用水 | 700ml |
| 奇异果 | 2 个 |
| 苹果 | 1/2 个 |
| 菠菜叶 | 4 叶 |
| 白砂糖 | 12 克 |

#### 操作

1.  将奇异果切成小块。
2.  将苹果切丁。
3.  菠菜叶去梗，只留叶子部分并切碎。
4.  将所有处理好的食材一同倒入榨汁机。
5.  加入水和白砂糖。
6.  启动搅拌机，分次搅拌，每次 15 秒，共约 4 次，每次间歇时观察状态。

#### 附加内容

-   白砂糖的用量可根据个人口味在 0-12g 之间调整。

### 柠檬水

![柠檬水成品](../../../dishes/drink/柠檬水/柠檬水.jpg)

**预估烹饪难度**：★

#### 必备原料和工具

-   **原料**: 柠檬、果蜜、冰块（可选）
-   **工具**: 雪克杯

#### 计算

一杯（约 500 毫升）分量：

| 原料 | 用量 |
| :--- | :--- |
| 柠檬 | 40-45 克 |
| 果蜜 | 40-45 克 |
| 冰块 | 若干（可选）|

#### 操作

1.  将 40-45 克柠檬放入雪克杯中。
2.  盖上盖子，用力捶打约 10 次，以释放柠檬汁和香气。
3.  加入 40-45 克果蜜。
4.  加水至适量。
5.  摇晃雪克杯直至所有成分混合均匀。
6.  根据个人喜好加入冰块。

### 泰国手标红茶

泰国手标红茶是泰国街头常见的奶茶，味道香醇、口感绵密。

**预估烹饪难度**：★★★

#### 必备原料和工具

-   **原料**: 水、茶粉、炼乳、白糖、牛奶
-   **工具**: 克称、带刻度容器、港式奶茶过滤袋

#### 计算

每份（1 人量）：

| 原料 | 用量 |
| :--- | :--- |
| 水 | 600cc |
| 茶粉 | 20g |
| 白糖 | 24g |
| 牛奶 | 18ml |
| 炼乳 | 24g |

#### 操作

1.  将 600cc 水用大火烧开。
2.  在过滤袋中装入 20g 茶粉，将开水冲入过滤袋，反复过滤 20 遍以萃取茶汤。
3.  在容量大于 1000ml 的水壶中，量取并放入 24g 炼乳、24g 白糖和 18ml 牛奶。
4.  将过滤好的热茶水倒入水壶中，搅拌至白糖完全融化。
5.  将水壶放入冰箱冷藏 4 小时以上。
6.  饮用前可加入 6-8 颗冰块。

### 百香果橙子特调

您可以根据喜好选择使用茉莉绿茶或苏打气泡水作为基底，口感各有风味。

![茉莉绿茶版本](../../../dishes/drink/百香果橙子特调/tea-version.jpg)

**预估烹饪难度**：★★★

#### 必备原料和工具

-   **原料**: 百香果、橙子、茉莉绿茶茶叶或苏打气泡水、白砂糖、冰块、蜂蜜（可选）、薄荷叶（可选，装饰用）
-   **工具**: 手动压汁器

#### 计算

以茉莉绿茶版本为例，一杯（约 380 毫升）分量：

| 部分 | 原料 | 用量 |
| :--- | :--- | :--- |
| **腌制百香果** | 百香果 | 3 个 |
| (两次用量) | 白砂糖 | 30 克 |
| | 蜂蜜 | 10 克 (或用5克糖代替) |
| **饮品主体** | 橙子 | 1 个 (约200克) |
| | 茉莉绿茶茶叶 | 3-6 克 |
| | 开水 | 150 毫升 |
| | 冰块 | 160 克以上 |

#### 操作

1.  **百香果腌制**：将 3 个百香果的果肉与汁液取出，与 30 克白砂糖和 10 克蜂蜜（或 5 克糖）搅拌均匀，密封后放入冰箱冷藏 12-24 小时。
2.  **茉莉绿茶调配**：用 150 毫升开水冲泡 3-6 克茶叶 6 分钟。然后加入 90 克冰块快速冷却，过滤掉茶叶，得到约 240 毫升的冷茶水。
3.  **橙子处理**：橙子对半切开，其中一半切一片备用，其余部分用压汁器压出橙汁。
4.  **正式调配**：
    -   在杯底放入 70 克冰块，倒入全部橙汁。
    -   将备用的橙子片贴着杯壁放入。
    -   将一半分量的腌制百香果浇在冰上。
    -   缓慢注入茉莉绿茶直至满杯，以形成漂亮的分层。
    -   用绿叶装饰即可。饮用前请搅拌均匀。

#### 附加内容

-   若使用苏打气泡水，可省略茉莉绿茶的调配步骤，直接在最后注入苏打水即可。

### 砂糖椰子冰沙

这是一款制作极其快速方便的饮料，口感丰富。但制作时动静较大，建议在白天进行。

**预估烹饪难度**：★

#### 必备原料和工具

-   瓶装椰汁（建议选用瓶口较大的）
-   咖啡调糖（黄色粗粒）

#### 计算

每份：

| 原料 | 用量 |
| :--- | :--- |
| 瓶装椰子汁 | 500ml |
| 咖啡调糖 | 10g (约2包) |
| 坚果碎 | 可选 |

#### 操作

1.  将 500ml 瓶装椰汁倒掉约 200ml（为结冰膨胀和后续摇晃留出空间），然后立即拧紧瓶盖。
2.  将瓶子放入冰箱冷冻区冷冻 10 小时以上，直至完全冻结。
3.  取出冻好的椰汁瓶，在墙角、椅背等坚硬表面上用力抽打，将瓶内冻块打碎成冰沙状（请确保所选表面不会因此受损）。
4.  当瓶内椰汁呈冰沙状态时，打开瓶盖倒出。
5.  在冰沙表面均匀撒上咖啡调糖或坚果碎即可完成。

### 耙耙柑茶

![耙耙柑茶](../../../dishes/drink/耙耙柑茶/citrus-tea.jpg)

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 耙耙柑（或丑橘等）、茉莉绿茶、冰块、蔗糖糖浆（可选）
-   **工具**: 搅拌机

#### 计算

一杯（约 300 毫升）分量：

| 原料 | 用量 |
| :--- | :--- |
| 耙耙柑 | 1-2 个 (200克以上) |
| 茉莉绿茶 | 2-4 克 |
| 冰块 | 60 克 |
| 1:1 蔗糖糖浆 | 10 克 (可选) |

#### 操作

1.  **茉莉绿茶调配**：用 100 毫升开水冲泡 2-4 克茶叶 6 分钟。加入 60 克冰块冷却，然后过滤掉茶叶，得到约 160 毫升冷茶水。
2.  **正式调配**：
    -   取出耙耙柑的果肉瓣，剥去外皮。
    -   取 130 克果肉和 130 毫升茉莉绿茶放入搅拌机中。
    -   根据口味加入 10 克蔗糖糖浆。
    -   启动搅拌机搅拌 20 秒，将混合物倒入杯中。
    -   取少量果肉撕碎撒在液面上作为装饰。

### 菠萝咖啡特调

这款特调非常适合家庭制作，酸甜可口，风味独特。

**预估烹饪难度**：★★★

#### 必备原料和工具

-   咖啡液（推荐浓缩或冷萃）
-   菠萝汁（鲜榨或 NFC）
-   冰块
-   苏打水
-   奶油
-   牛奶
-   糖
-   海盐（可选）
-   朗姆酒（可选，加入后会成为含酒精饮品）

#### 计算

每份（1 人量）：

| 原料 | 用量 |
| :--- | :--- |
| 咖啡液 | 30ml |
| 菠萝汁 | 60ml |
| 冰块 | 50g |
| 苏打水 | 30ml |
| 奶油 | 30ml |
| 牛奶 | 10ml |
| 糖 | 8g |
| 海盐 | 0.5g (可选) |
| 朗姆酒 | 5ml (可选) |

#### 操作

1.  在杯中依次加入冰块、咖啡液、菠萝汁和苏打水。
2.  将奶油与糖一同打发至湿性发泡，然后加入朗姆酒（可选）和牛奶，搅拌均匀至具有流动性的奶盖状态。
3.  将调制好的奶油缓缓倒在饮品上方。
4.  在奶油顶面撒上海盐即可。

### 酒酿醪糟

酒酿，也叫醪糟，是一道传统中式发酵甜品。成品清甜微醺，含少量酒精，具有健脾开胃的功效。

**预估烹饪难度**：★★★★

#### 必备原料和工具

-   **原料**: 糯米 800g（推荐圆糯米）、安琪甜酒曲 8g、清水 720g + 600g
-   **工具**: 蒸锅（电饭煲即可）、温度计（推荐）、干净的密封玻璃或陶瓷容器

#### 操作

1.  将 800g 糯米淘洗干净，加入 720g 清水，用电饭煲蒸熟。
2.  蒸熟后将米饭倒出，摊凉至 30°C（体感温热不烫手）。
3.  将 8g 酒曲用 20ml 温水化开，均匀撒在糯米饭中，同时加入 600g 清水帮助翻拌均匀。
4.  将混合好的米饭装入干净的容器中，轻轻压平表面，并在中央挖一个小洞以便观察出酒情况。
5.  盖上盖子或保鲜膜密封，放置于 28-32°C 的温暖环境中发酵 24-48 小时。
6.  发酵成功的标准是中间凹槽有透明酒液渗出，且整体带有酒香。成功后即可移入冰箱冷藏保存。

#### 附加内容

-   发酵温度至关重要，过低或过高都可能导致失败。
-   所有接触糯米饭的容器和工具都必须确保无油、无生水。

### 酸梅汤

**预估烹饪难度**：★★★★

#### 必备原料和工具

| 原料 | 用量 |
| :--- | :--- |
| 水 | 约 2.1 升 |
| 乌枣 | 25 克 |
| 乌梅 | 25 克 |
| 生山楂片 | 30 克 |
| 黄冰糖 | 100 克 |
| 甘草 | 2 克 |
| 陈皮 | 4 克 |
| 红豆蔻 | 1 克 |
| 干桂花 | 3 克 |

#### 操作

1.  将除干桂花和冰糖外的所有材料冲洗干净，用 1.5 升水浸泡两小时以上。
2.  开中大火煮沸，然后转小火继续煮 40 分钟（此为头煎）。
3.  将头煎的汤汁沥出，趁热倒入装有冰糖的盆中，搅拌至冰糖完全融化。
4.  将锅中的药材重新加入 600 毫升水，大火煮沸后转中火再煮 20 分钟（此为二煎）。
5.  将二煎的汤汁与之前的冰糖水混合。
6.  待成品温度降至 60-70℃ 时加入干桂花，加盖晾凉后放入冰箱冷藏 3 小时以上。饮用时过滤掉桂花即可。

### 杨枝甘露

这是一款经典的港式甜品。本食谱使用奇亚籽代替传统的西米，制作更方便快捷。

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 奇亚籽、牛奶、冰块、芒果、葡萄柚、椰奶
-   **工具**: 调理机/果汁机

#### 计算

每份：

| 原料 | 用量 |
| :--- | :--- |
| 奇亚籽 | 24g |
| 牛奶 | 50ml |
| 冰块 | 2 小块 |
| 芒果 | 1 粒 |
| 葡萄柚 | 1/2 粒 |
| 椰奶 | 150ml |
| 切丝芒果干/柳橙干 | 可选，点缀用 |

#### 操作

1.  将奇亚籽用牛奶浸泡 10 分钟。
2.  在浸泡奇亚籽的同时，将半粒芒果和葡萄柚去皮切丁，放入杯中。
3.  将另外半粒芒果切小块，与冰块、椰奶一同放入调理机打成顺滑的果泥。
4.  将打好的芒果泥倒入杯中，在顶部放上点缀材料即可。

### 酸梅汤（半成品加工）

使用市售酸梅晶制作的快速版本，省时省力。

**预估烹饪难度**：★

#### 必备原料和工具

-   酸梅晶固体饮料
-   方糖（可选）
-   北京二锅头酒（可选，加入后会成为含酒精饮品）

#### 计算

| 原料 | 用量 |
| :--- | :--- |
| 饮用水 | 1177 克 |
| 酸梅晶固体饮料 | 120 克 |
| 方糖 | 9 克 (可选) |
| 北京二锅头酒 | 48 克 (可选) |

#### 操作

1.  在 1177 克饮用水中先加入 60 克酸梅晶，搅拌 50 圈。
2.  再加入剩下的 60 克酸梅晶，再次搅拌 50 圈。
3.  根据口味加入 9 克方糖，搅拌 100 圈直至溶解（可选）。
4.  加入 48 克二锅头酒，搅拌 30 圈（可选）。
5.  放入冰箱冷藏后饮用效果更佳。

### 奶茶

最基础的自制奶茶配方，简单易做，原料易得。

**预估烹饪难度**：★★

#### 必备原料和工具

-   袋泡红茶（推荐立顿黄牌精选红茶）
-   全脂奶粉或淡奶
-   砂糖
-   杯子

#### 计算

每份：

| 原料 | 用量 |
| :--- | :--- |
| 袋泡红茶 | 2 包 (约4g) |
| 奶粉 | 11-12g |
| 砂糖 | 5-7g |
| 沸水 | 180-200mL |

#### 操作

1.  将 2 包袋泡红茶放入杯中，加入 180-200mL **沸水**。
2.  盖上盖子，焖泡 20 - 30 分钟，以充分萃取茶味。
3.  取出茶包，加入 11-12g 奶粉和 5-7g 砂糖。
4.  搅拌均匀即可饮用。

### 冬瓜茶

清爽的传统饮料，适合夏季消暑。制作出的浓缩汁可以保存，随时兑水饮用。

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 冬瓜、冰糖
-   **工具**: 保鲜膜、过滤网、大锅

#### 计算

每份（4-5 人量）：

| 原料 | 用量 |
| :--- | :--- |
| 冬瓜 | 1000g |
| 冰糖 | 300g |

#### 操作

1.  将冬瓜去皮去籽，切成小块。
2.  将冬瓜块与冰糖搅拌均匀，盖上保鲜膜，放入冰箱冷藏 2 小时以上，利用渗透压让冬瓜出水。
3.  将出了水的冬瓜和冰糖一同倒入锅中，大火煮开后转中小火熬制 1-2 小时，期间需多次搅拌以防糊锅。
4.  使用过滤网将熬好的液体过滤出来，即为冬瓜茶浓缩汁。
5.  冷却后装入干净容器中冷藏保存。饮用时根据个人喜好兑水稀释即可。

## 酒精特调

本节包含所有含酒精的饮品，请适度享用。

### 海边落日

**预估烹饪难度**：★★★

#### 必备原料和工具

-   **原料**: 红石榴糖浆、NFC 橙汁、苏打水、白朗姆、蓝橙力娇酒、柠檬汁、冰块、柠檬片
-   **工具**: 大号玻璃杯、搅拌棒、量酒器、调酒杯

#### 计算

一杯分量：

| 原料 | 用量 |
| :--- | :--- |
| 红石榴糖浆 | 15ml |
| 橙汁 | 35-50ml |
| 苏打水 | 50ml |
| 白朗姆 | 30ml |
| 蓝橙力娇酒 | 15ml |
| 柠檬汁 | 15ml |
| 大冰块 | 适量 |
| 柠檬片 | 1 片 |

#### 操作

1.  在玻璃杯中放入大冰块，用搅拌棒搅拌以冰杯。
2.  在杯底加入红石榴糖浆。
3.  将橙汁沿搅拌棒缓慢导入杯中，至杯子一半高度。
4.  轻轻搅拌半圈，然后倒入苏打水。
5.  在调酒杯中加入白朗姆、蓝橙力娇酒、柠檬汁和冰块，摇晃均匀。
6.  将调酒杯中的混合物轻轻地、缓慢地倒入玻璃杯中，使其在橙汁上方形成分层。
7.  用柠檬片和吸管装饰。

### 金汤力

![金汤力](../../../dishes/drink/金汤力/gin-tonic.jpg)

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 金酒、汤力水、柠檬、冰块、新鲜绿叶（可选）
-   **工具**: 手动压汁器

#### 计算

一杯（约 350 毫升）分量：

| 原料 | 用量 |
| :--- | :--- |
| 金酒 | 30-40 毫升 |
| 汤力水 | 1 罐 |
| 柠檬 | 1 个 |
| 冰块 | 100 克 |

#### 操作

1.  将一个柠檬对半切，一半切片备用，另一半压出柠檬汁。
2.  在玻璃杯中放入 100 克冰块。
3.  倒入 30-40 毫升金酒和 15 毫升柠檬汁（可按个人酸度喜好调整）。
4.  用勺子搅拌均匀。
5.  放入备用的柠檬片作为装饰。
6.  缓慢沿杯壁注入汤力水直至满杯，以保留气泡。
7.  用勺子轻轻上下提拉搅拌几下即可。
8.  用新鲜绿叶装饰（可选）。

### 金菲士

![金菲士](../../../dishes/drink/金菲士/gin-fizz.jpg)

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 金酒、苏打水、柠檬、蔗糖糖浆、冰块、新鲜绿叶（可选）
-   **工具**: 手动压汁器、雪克瓶（可选）

#### 计算

一杯（约 350 毫升）分量：

| 原料 | 用量 |
| :--- | :--- |
| 金酒 | 30-40 毫升 |
| 苏打气泡水 | 1 罐 |
| 柠檬 | 1 个 |
| 1:1 蔗糖糖浆 | 30-40 克 |
| 冰块 | 100 克 |

#### 操作

1.  将一个柠檬对半切，一半切片备用，另一半压出柠檬汁。
2.  **（有雪克瓶）**：将冰块、金酒、柠檬汁、蔗糖糖浆倒入雪克瓶，摇晃至瓶身冰冷，然后将混合物倒入杯中。
3.  **（无雪克瓶）**：在杯中放入冰块，依次倒入金酒、柠檬汁、蔗糖糖浆，用勺子搅拌均匀。

5.  缓慢沿杯壁注入苏打水直至满杯。
6.  用勺子轻轻上下提拉搅拌。
7.  用新鲜绿叶装饰（可选）。

### Mojito（莫吉托）

Mojito 是一种传统的古巴高球鸡尾酒，酒精含量相对较低（约 10%）。

**预估烹饪难度**：★★★

#### 必备原料和工具

-   **原料**: 青柠、薄荷叶、糖浆、金色朗姆酒、伏特加、碎冰、冰镇苏打水
-   **工具**: 海波杯、研杵

#### 计算

每份：

| 原料 | 用量 |
| :--- | :--- |
| 青柠 | 1 块 (切半) |
| 薄荷叶 | 5 株 |
| 糖浆 | 20ml |
| 金色朗姆酒 | 45ml |
| 伏特加 | 10ml |

#### 操作

1.  将半块青柠切成小块放入海波杯，用研杵捣压出汁。
2.  取 3-4 株薄荷叶，用手掌拍醒以释放香气，沿杯口涂抹后放入杯中。
3.  加入糖浆和朗姆酒。
4.  将剩下的半块青柠压出汁水滴入杯中，轻轻搅拌。
5.  加入碎冰至杯中 3/4 处，再加入冰镇苏打水至刚好淹没碎冰。
6.  旋转搅拌半分钟，然后用碎冰补满杯子。
7.  将剩下的一株薄荷叶拍醒，插入碎冰中作为装饰。

### B52 轰炸机

B-52 是一款喝法独特的鸡尾酒，需要点燃后用吸管一口气喝完，以体验冰火两重天的感觉。

**预估烹饪难度**：★★★

#### 必备原料和工具

-   **原料**: 甘露咖啡酒、爱尔兰百利甜酒、伏特加
-   **工具**: 吧勺、利口酒杯、打火机

#### 计算

每份（各 10ml）：

| 原料 | 用量 |
| :--- | :--- |
| 甘露咖啡酒 | 10ml |
| 爱尔兰百利甜酒 | 10ml |
| 伏特加 | 10ml |

#### 操作

1.  在利口酒杯的最底层倒入 10ml 甘露咖啡酒。
2.  将吧勺背面朝上，抵住杯壁内侧，缓缓倒入 10ml 百利甜酒，使其浮在咖啡酒上层。
3.  用同样的方法，在上层缓缓倒入 10ml 伏特加。
4.  用打火机点燃顶层的伏特加，即可看到淡蓝色的火焰。

#### 附加内容

-   饮用时，将吸管插入杯底，快速将三层酒液全部吸入口中。火焰会因吸管内缺氧而熄灭，不必担心。

### 长岛冰茶

长岛冰茶虽名为“茶”，却不含茶，是一款由多种烈酒混合调制而成的高酒精度（约 15%）鸡尾酒，但口感柔和易于入口。

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 金酒、龙舌兰酒、伏特加、白朗姆酒、橙味甜酒、柠檬汁、枫糖浆、可乐、冰块
-   **工具**: 高球杯

#### 计算

一杯（约 300ml）分量：

| 原料 | 用量 |
| :--- | :--- |
| 金酒 | 15ml |
| 龙舌兰酒 | 15ml |
| 伏特加 | 15ml |
| 白朗姆酒 | 15ml |
| 橙味甜酒 | 15ml |
| 柠檬汁 | 30ml |
| 枫糖浆 | 20ml |
| 可乐 | 75ml |
| 冰块 | 100 克 |

#### 操作

1.  在高球杯中挤入 30ml 柠檬汁。
2.  依次向杯中加入金酒、龙舌兰酒、伏特加、白朗姆酒和橙味甜酒。
3.  缓慢倒入 20ml 枫糖浆，边倒边搅拌。
4.  加入 75ml 可乐。
5.  最后加入冰块直至满杯，轻轻搅拌 20 秒即可。

### 可乐桶

因冰块和可乐的口感能有效掩盖威士忌的酒味，饮用者容易在不知不觉中过量饮酒。请务必在保证安全的情况下调配和享用。

**预估烹饪难度**：★★

#### 必备原料和工具

-   **原料**: 波旁威士忌、可口可乐、冰块、柠檬（可选）
-   **工具**: 大容量杯子（玻璃杯或铁皮酒桶）

#### 计算

一杯（约 900 毫升）分量：

| 原料 | 用量 |
| :--- | :--- |
| 威士忌 | 100 毫升 |
| 可口可乐 | 500 毫升 |
| 柠檬 | 1 个 (可选) |
| 冰块 | 300 克 |

#### 操作

1.  （可选）将柠檬切片或榨汁备用。
2.  在大型杯子中放入 300 克冰块和处理过的柠檬。
3.  （可选）倒入 15 毫升柠檬汁。
4.  沿杯壁缓慢倒入 500 毫升可口可乐。
5.  最后倒入 100 毫升威士忌直至满杯。
