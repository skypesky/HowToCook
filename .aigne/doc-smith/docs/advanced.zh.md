## 高级专业术语

如同学习一门编程语言需要掌握其语法，深入烹饪艺术同样需要理解一系列专业术语。这些术语是烹饪操作的精确描述，掌握它们是提升厨艺的基石。

| 术语 | 解释 |
| :--- | :--- |
| **炒 (chǎo)** | 将食物切成小件，放入烧热的油锅中迅速翻搅至熟，并加入调料调味。 |
| **炝 (qiàng)** | 食材经沸水或热油处理后，在热锅中爆入干辣椒和花椒油拌匀。 |
| **炊 (chuī)** | 利用蒸、煮等方法将食物弄熟。 |
| **煮 (zhǔ)** | 在锅中用适量的沸水或汤水及调味料将食物煮熟。 |
| **煎 (jiān)** | 锅烧热放少许油，将食物平摊紧贴锅面，用慢火热油使其表面金黄并熟透。 |
| **爆 (bào)** | 利用热锅热油，快速加入调好的汁酱或汤水，使小件食物迅速成熟并附上香气。 |
| **炸 (zhá)** | 将食物放入大量热油中使其熟透至酥脆。 |
| **烚 (xiá)** | 用大量沸水将较韧的肉类在炉火上煮软煮熟。 |
| **滚 (gǔn)** | 利用大量沸水的涌动去除食物的腥膻味。 |
| **汆 (cuān)** | 将加工成丸或片的食物在沸水中烫熟，捞入碗中再加入沸汤。 |
| **灼 (zhuó/chāo)** | 将食物切薄片，用沸水迅速烫熟，再蘸酱料食用。 |
| **炟 (dá)** | 将蔬菜放入加有枧水或生油的沸水中慢火煮透，使其保持翠绿和软嫩。 |
| **涮 (shuàn)** | 将切薄的食物放入辣汤中烫熟，再蘸酱料食用。 |
| **煀 (kuò)** | 将食物直接放入锅中，加入大量姜葱等香料，盖盖焖熟，使其充满香气。 |
| **焗 (jú)** | 利用灼热的粗盐等介质，在密封条件下将用纸包好的食物弄熟。 |
| **焖 (mèn)** | 将较韧的食物放入锅中，加适量汤水，盖上盖用文火煮软煮熟。 |
| **炆 (wén)** | 类似于北方的“烧”，指用文火将较韧的食物加汤水煮软煮熟。 |
| **烩 (huì)** | 用适量的汤水将多种肉料和蔬菜一同烹煮。 |
| **蒸 (zhēng)** | 利用水蒸气的热力使食物成熟。 |
| **炖 (dùn)** | 将食物加入汤水，放入有盖容器中，利用水蒸气长时间加热至熟并形成汤汁。 |
| **扣 (kòu)** | 食物预处理后整齐排入碗中蒸熟，再倒扣入盘中，淋上原汁勾芡的芡汁。 |
| **煲 (bāo)** | 将食物放入大量清水中，用慢火长时间煮出汤水。 |
| **熬 (áo)** | 用慢火长时间将肉料的鲜味融入汤中，并使汤汁浓缩。 |
| **煨 (wēi)** | 利用姜葱和汤水为食物去异增香，或将食物放入密封瓦坛中文火煮熟。 |
| **烘 (hōng)** | 将调味或加工好的食物置于烘炉中烤熟。 |
| **煸 (biān)** | 在热锅中不断翻炒食物，使其水分略干，以去除异味并浓缩鲜味。 |
| **溜 (liū)** | 用酸甜的汁水勾芡，使经过酥炸的食物口感滑嫩。 |
| **羹 (gēng)** | 将切丁的食物用沸汤煮后，加入湿淀粉使汤汁变稠。 |
| **攒 (zǎn)** | 分“攒油”或“攒酒”，前者指热油泼在蒸熟的食物上，后者指烹煮时烹入绍酒以增香气。 |
| **卤 (lǔ)** | 利用由酱油和香料调制的卤水汁使食物成熟或入味。 |
| **酱 (jiàng)** | 利用大量的酱汁或酱油使食物入味或成熟。 |
| **浸 (jìn)** | 利用“菊花心”（微沸）状态的热水或汤水，在一定时间内将食物浸熟。 |
| **飞水/焯水** | 将原料放入沸水中短暂加热至半熟后捞出，为后续烹饪做准备。 |
| **勾芡 (gōuqiàn)** | 在烹饪过程中加入淀粉水溶液，使汤汁达到一定稠度。 |
| **高汤** | 又称“清汤”，是用肉、骨等原料熬制后，经过特殊处理得到清澈味浓的汤料。 |
| **奶汤** | 又称“白汤”，是将原料加清水煨煮而成的色泽乳白的汤。 |

## 核心技巧

掌握核心的烹饪技巧，是提升菜品质量的关键。以下将介绍油温判断、糖色炒制和辅料运用三个方面的高级技巧。

### 油温判断技巧

精确控制油温是许多烹饪手法的成败关键。网络视频教程中常说的“几成油温”，通常指相对于 300°C 的“十成油温”。即 n 成油温 ≈ 30 \* n (°C)。为了精确控制，建议使用厨房专用的油温枪。

*   **120°C - 140°C (四成热)**：适合软炸、滑炒。将筷子放入油锅，周围基本不起泡，油面平静，无青烟。
*   **150°C - 160°C (五成热)**：最佳烹饪温度。筷子周围会冒出少量油泡，油面从四周向中间翻动，略有青烟。
*   **160°C - 180°C (六成热)**：适合上色和炸酥。油面反而较为平静，但有大量青烟上升。

### 糖色的炒制

糖色是许多红烧类菜肴色泽和风味的关键。其原理是糖在高温下融化并发生焦糖化反应。推荐使用油炒法，更易成功。

**油炒法（推荐）**

以炒制 200ml 糖色为例：

1.  选择锅底有弧度或平底面积较小的锅。
2.  锅中加入 8g 冰糖（或白砂糖）和 10ml 常温食用油。
3.  开小火加热，用锅铲不断搅拌混合物。如用冰糖，可轻敲使其破碎以加速融化。
4.  待糖全部融化，混合物呈粘稠透明偏白色。
5.  继续搅拌，颜色会逐渐变为白色，然后是浅棕色，最后到明显的棕色。
6.  当混合物呈棕色并出现绵密的小气泡，且小气泡中开始出现较大的气泡时，糖色初步炒好。
7.  此时，向锅中加入 190ml 约 70°C 的热水。锅中液体会呈现深红棕色、清澈透明，并带有焦糖香味。
8.  倒入碗中，即可获得约 200ml 糖色。

> [!Note]
> 加入热水时，请务必小心，防止热油和糖浆溅出。不建议使用冷水，低温会导致糖凝固粘锅。

**糖浆状态及用途**

| 状态 | 制备阶段（参照步骤） | 用途示例 |
| :--- | :--- | :--- |
| 未完全融化糖浆 | 步骤 4 后 | 挂霜山楂 |
| 完全融化糖浆 | 步骤 5 初期 | 冰糖葫芦 |
| 焦糖 | 步骤 6 后自然冷却 | 焦糖 |
| 糖色 | 步骤 7 完成后 | 红烧肉等 |

*   **技巧**：在烹饪红烧肉等小块食材时，可以在第 7 步加水前，直接下入食材快速翻炒，使食材均匀裹上糖色，然后再加水，这样上色更快更均匀。

### 辅料技巧

辅料的正确使用能极大地提升菜肴的香味层次。

**投放顺序**

*   **基本顺序**：先放姜，后放葱和蒜、辣椒，再放八角、花椒等干料，最后放干辣椒。
*   **原理**：
    *   **姜**：含水量大，需要更长时间煸出汁水和香味。
    *   **葱蒜**：葱段比葱花/蒜末需要更长的时间出香。
    *   **干料**：对于炒菜，可先放干料让油更香。但对于炖、焖等需要长时间翻炒其他辅料的菜，后放可避免干料变黑变苦。
    *   **干辣椒**：极易变黑，入锅翻炒几秒即可。
*   **要点**：无论何种菜系，用小火将这些辅料炒至金黄，都可以将整道菜变得更有香味，这是调料所不能给予的。

**放盐时机与盐量控制**

*   **快炒料理**：先加盐。盐量约为食材总重量的 0.9%。
*   **肉食料理**：八成熟时加盐。盐量约为（食材总重量 + 30mL 汁水）的 1%～1.2%。
*   **汤品**：出锅前最后加盐。盐量约为初始水量的 0.8%。
*   **健康提示**：根据世界卫生组织（WHO）建议，成人每日总盐量不应超过 5 克。
