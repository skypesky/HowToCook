## 反沙芋头

反沙芋头是一道著名的潮汕小吃，制作简便，口感外脆内糯，甜而不腻。

![反沙芋头成品](../../../dishes/dessert/反沙芋头/反沙芋头成品.jpg)

- **预计制作时间**：20 分钟
- **预估烹饪难度**：★★★☆☆

### 必备原料与工具

| 原料/工具 | 说明 |
| :--- | :--- |
| 荔浦芋头 | 建议电商平台购买，品质较好 |
| 白砂糖 | 或冰糖 |
| 水 | |
| 葱 | |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 荔浦芋头 | 200g |
| 白砂糖 | 30g |
| 水 | 15g |

### 操作

1.  芋头去皮，切成稍粗的长条，以便在翻炒过程中不易碎烂。
2.  锅中倒入足量食用油，能没过芋头条为佳。加热油温，当插入筷子时周围冒起小泡即可。
3.  放入芋头条，炸至芋头浮起，表面呈微微泛黄，且能用筷子轻松戳穿。
4.  捞出炸好的芋头，炸芋头的油可留作他用。
5.  锅中留底油，将白砂糖（30g）和水（15g）按 2:1 的比例下锅，加热至糖水不变色且冒小泡。
6.  倒入葱花和炸好的芋头条，立即关火，持续翻炒。
7.  随着温度下降，糖分会重新结晶，在芋头表面形成一层白霜，即“反沙”效果。
8.  装盘即可享用。

### 附加内容

- 刚出锅的反沙芋头温度很高，请小心食用，以免烫伤。
- 搭配一杯清茶，可以平衡甜腻感，风味更佳。

## 咖啡椰奶冻

咖啡椰奶冻是一道制作简单的甜品，口感顺滑，融合了咖啡的醇香与椰奶的清甜。

![咖啡椰奶冻](../../../dishes/dessert/咖啡椰奶冻/咖啡椰奶冻.png)

- **预计制作时间**：1 小时（不含冷藏时间）
- **预估烹饪难度**：★★★★☆

### 必备原料与工具

| 原料/工具 | 说明 |
| :--- | :--- |
| 淡奶油 | |
| 椰树牌椰汁 | |
| 意式浓缩咖啡 | 不推荐使用果酸风味的咖啡豆 |
| 椰子水 | 推荐 vita coco 品牌，或使用新鲜椰子水 |
| 吉利丁(gelatin) | |
| 过滤网 | 可选，用于提升口感 |
| 蓝莓/咖啡粉 | 可选，用于摆盘装饰 |

### 计算 (3-4 人份)

| 原料 | 用量 |
| :--- | :--- |
| 淡奶油(35% M.E) | 125ml |
| 椰树牌椰汁 | 250ml |
| 意式浓缩咖啡 | 35ml |
| 椰子水 | 50ml |
| 吉利丁 | 10g |
| 糖 | 可选，根据个人口味添加 |

### 操作

1.  将淡奶油、椰树牌椰汁、意式浓缩咖啡和椰子水混合备用。
2.  将混合液体加热约 1 分钟，达到 50-60°C 即可，**请勿煮沸或冒泡**。
3.  如果需要增加甜度，可在此步加入额外的糖。
4.  倒入吉利丁，搅拌至完全融化，继续煮 1 分钟。
5.  （可选）使用过滤网过筛，使椰奶冻口感更顺滑。
6.  将液体倒入模具中。
7.  （可选）用勺子撇去表面的气泡，成品外观更佳。
8.  放入冰箱冷藏区，冷藏至少 3 小时待其凝固。

### 附加内容

- **注意事项**：加热液体时务必不要煮沸，否则会影响吉利丁的凝固效果。
- **厨具清洗**：吉利丁较难清洗，建议使用洗碗机或温水清洗。

## 奥利奥冰淇淋

这款奥利奥冰淇淋制作简单，口感纯正，使用动物奶油，甜而不腻。

- **预计制作时间**：30 分钟（不含冷冻时间）
- **预估烹饪难度**：★★★☆☆

### 必备原料与工具

| 原料/工具 | 说明 |
| :--- | :--- |
| 淡奶油 | 推荐安佳动物淡奶油 |
| 原味奥利奥 | |
| 白砂糖 | |
| 电动打蛋器 | |
| 深容器 | 容量 600ml 以上，直径需能容纳打蛋器 |
| 小刀 | 用于去除奥利奥夹心 |
| 冰淇淋模具 | 可选 |

### 计算 (每份)

| 原料 | 用量 |
| :--- | :--- |
| 奥利奥 | 6 块 |
| 白砂糖 | 18 克 |
| 淡奶油 | 250 毫升 |

### 操作

1.  将奥利奥饼干拧开，用小刀刮去夹心。
2.  将去除夹心的饼干用工具捣碎，一半呈粉末状，另一半为小于 0.5 厘米的碎块。（也可直接购买“奥利奥饼干碎”）
3.  将淡奶油和白砂糖倒入深容器中。
4.  使用电动打蛋器高速搅打，直至提起打蛋器时，奶油能挂在打蛋头上形成 0.5 - 1 厘米的尖角，而不是完全流下。
5.  将准备好的奥利奥碎倒入打发好的奶油中，用刮刀搅拌均匀。
6.  将混合物倒入容器或冰淇淋模具中。
7.  放入冰箱冷冻室（-18°C）冷冻 4 小时以上即可。

### 附加内容

- 捣碎奥利奥时，请使用坚固的容器，避免使用易碎品。
- 去除奥利奥夹心时请注意安全，防止割伤。

## 戚风蛋糕

戚风蛋糕是烘焙入门的经典之作，口感细腻绵软。虽然有一定操作难度，但掌握要领后成功率会大大提高。

![成品](../../../dishes/dessert/戚风蛋糕/DSC08716.jpg)

- **预计制作时间**：1.5 - 2 小时
- **预估烹饪难度**：★★★★★

### 必备原料与工具

| 类别 | 原料/工具 | 说明 |
| :--- | :--- | :--- |
| **工具** | 烤箱 | 电饭锅可替代但成功率较低 |
| | 打蛋器 | 推荐电动，手动费力且易失败 |
| | 铝合金阳极模具 | **切勿**使用不粘模具，常用为 6 寸或 8 寸 |
| | 刮刀 | 用于翻拌蛋糕糊 |
| **原料** | 鸡蛋 | |
| | 白糖 | |
| | 牛奶 | 或用水替代 |
| | 食用油 | 或加热软化的黄油 |
| | 低筋面粉 | 推荐惠宜品牌 |
| | 柠檬汁或白醋 | 可选，有助于稳定蛋白霜 |

### 计算

| 模具尺寸 | 鸡蛋 | 白糖 | 食用油 | 牛奶 | 低筋面粉 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **6 寸** | 3 个 | 50g | 25g | 30g | 50g |
| **8 寸** | 5 个 | 80g | 40g | 50g | 90g |

### 操作

#### 1. 前期分离操作

1.  准备两个**洁净干燥**的容器。盛放蛋清的容器**绝不能有任何油污**，盛放蛋黄的容器不能有水珠。
2.  将鸡蛋的蛋清与蛋黄分离，分别放入两个容器中。蛋清中**绝不能混入蛋黄**。

#### 2. 搅拌蛋黄糊

1.  在另一个碗中，先加入食用油，再筛入低筋面粉，初步搅拌。
2.  加入蛋黄、牛奶以及 **1/4** 的白糖，用刮刀以“Z”字形手法搅拌均匀，直至无干粉状态。
3.  静置备用。

#### 3. 打发蛋白

1.  将剩余 **3/4** 的白糖平均分成三份。
2.  （可选）在蛋清中滴入几滴柠檬汁或白醋。
3.  用打蛋器中速搅打蛋清至出现**粗大气泡**，加入第一份白糖。
4.  转高速继续搅打至**气泡变细腻**，加入第二份白糖。
5.  继续高速搅打至**湿性发泡**状态（提起打蛋器有长长的弯钩），加入第三份白糖。
6.  转中低速搅打，直至达到**干性发泡**状态（提起打蛋器有短小直立的尖角，倒扣容器蛋白不掉落）。

#### 4. 混合搅拌

1.  取 **1/3** 的蛋白霜加入蛋黄糊中，用刮刀采用**翻拌**（类似炒菜）的手法混合均匀，避免消泡。
2.  将混合好的蛋糕糊倒回剩余的 **2/3** 蛋白霜中，继续用翻拌手法混合均匀。
3.  将最终的蛋糕糊倒入模具中，轻轻震几下以消除大气泡。

#### 5. 烘烤

1.  烤箱提前预热，上管 150°C，下管 160°C。
2.  将模具放入烤箱下层，采用变温烘烤：
    *   **第一阶段**：上管 150°C，下管 160°C。烘烤总时长的 **3/5**。
    *   **第二阶段**：上管 160°C，下管 170°C。烘烤总时长的 **2/5**。
3.  **参考总时间**：6 寸蛋糕约 30-35 分钟，8 寸蛋糕约 50 分钟。请根据自家烤箱特性适当调整。
4.  烤好后立即出炉，注意防烫。

#### 6. 冷却与脱模

1.  （可选）将模具从高处轻摔一下，震出热气。
2.  立即倒扣在冷却架上，等待完全冷却（约 10 分钟）。
3.  待蛋糕完全冷却后，进行脱模。

### 附加内容

- **关键点**：戚风蛋糕成功的关键在于**烤制时的温度和时间控制**，其次才是蛋白打发。
- **蛋清状态**：刚从冰箱取出的鸡蛋易于分离蛋清蛋黄，但恢复至室温的蛋清更容易打发。
- **翻拌手法**：正确的翻拌手法是避免蛋白消泡、蛋糕塌陷的核心技巧。

## 提拉米苏

提拉米苏是经典的意大利甜品，制作过程无需烤箱，对新手非常友好。

![自家提拉米苏成品](../../../dishes/dessert/提拉米苏/提拉米苏成品.jpg)

- **预计制作时间**：30 分钟（不含冷藏时间）
- **预估烹饪难度**：★★★★☆

### 必备原料与工具

| 原料/工具 | 说明 |
| :--- | :--- |
| 马斯卡彭芝士 | |
| 手指饼干 | |
| 浓缩咖啡 | 需提前准备并放凉 |
| 无菌鸡蛋 | |
| 白砂糖 | |
| 可可粉 | 用于表面装饰 |
| 朗姆酒 | 可根据喜好添加或省略 |
| 打蛋器 | |
| 成品容器 | |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 马斯卡彭芝士 | 450g |
| 手指饼干 | 1 包 |
| 放凉浓缩咖啡 | 350ml |
| 无菌鸡蛋 | 4 个 |
| 白砂糖 | 50g |
| 可可粉 | 10g |
| 朗姆酒 | 35ml |

### 操作

1.  分离蛋黄和蛋清。
2.  在盛有蛋清的碗中加入 10g 白砂糖，打发至湿性发泡。
3.  在盛有蛋黄的碗中，分三次加入 40g 白砂糖，搅拌均匀。
4.  将马斯卡彭芝士分三次加入蛋黄液中，搅拌至顺滑均匀。
5.  在蛋黄芝士糊中加入朗姆酒，搅拌均匀。
6.  将打发好的蛋白分三次加入蛋黄芝士糊中，用翻拌手法混合均匀，制成芝士糊。
7.  取一块手指饼干，在咖啡液中快速浸湿两面，平铺在容器底部。
8.  铺上一层芝士糊，再铺一层浸湿的饼干，如此交替，直至用完所有材料。
9.  将容器放入冰箱冷藏至少 4 小时。
10. 食用前，在表面均匀筛上一层可可粉即可。

### 附加内容

- 关于蛋白打发的详细教程，可参考[下厨房的相关指南](https://www.xiachufang.com/recipe/101779500/)。

## 无厨师机蜂蜜面包

这款蜂蜜面包无需厨师机，主要依靠时间进行发酵，口感松软，适合提前一晚准备，第二天烘烤。

![自家成品](../../../dishes/dessert/无厨师机蜂蜜面包/无厨师机蜂蜜面包.jpg)

- **预计制作时间**：30 分钟操作时间，发酵时间较长
- **预估烹饪难度**：★★★★★

### 必备原料与工具

| 类别 | 原料 |
| :--- | :--- |
| **面包本体** | 高筋面粉、牛奶、酵母、鸡蛋、白砂糖、盐、黄油 |
| **蜂蜜水** | 蜂蜜、水 |
| **顶部装饰** | 芝麻（可选） |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 高筋面粉 | 400g |
| 牛奶 | 200g |
| 酵母 | 4g |
| 鸡蛋 | 1 个 |
| 白砂糖 | 70g |
| 盐 | 2g |
| 黄油 | 30g |
| 蜂蜜 | 20g |
| 水 | 20g |

### 操作

1.  **制作面团**：将高筋面粉、温牛奶（约 40°C）、酵母、鸡蛋、糖和盐混合均匀成团。
2.  加入软化的黄油，用手继续揉搓，直至黄油被完全吸收。
3.  用保鲜膜覆盖容器，在室温下（10-20°C）发酵 1-2 小时，或直至面团膨胀至原先的 2 倍大。
4.  **分割整形**：将发酵好的面团取出，分割成每份约 60g 的小面团。
5.  将小面团擀成舌状后卷起，静置醒面 10 分钟。
6.  再次擀卷，可重复此步骤数次，使面包层次更丰富。
7.  **二次发酵**：在烤盘上铺上油纸并刷一层油。将整形好的面团底部蘸少量水和面粉，放入烤盘。
8.  盖上保鲜膜进行二次发酵。此步可将烤盘放入冰箱冷藏过夜，第二天再烤。
9.  **烘烤**：烤箱预热至 180°C (355°F)。在面团表面刷上一层蛋液。
10. 放入烤箱烘烤 18-20 分钟。
11. 出炉后，立即刷上一层蜂蜜水，并撒上芝麻（可选）。

### 附加内容

- **发酵判断**：发酵时间并非固定，关键是观察面团状态，膨胀至 2-2.5 倍大即可。
- **储存**：面包冷却后可放入冰箱储存，食用前用微波炉加热 10-20 秒即可恢复松软。

## 炸鲜奶

炸鲜奶是一道外酥里嫩的经典甜点，制作难度中等，口感独特。

![炸鲜奶成品](../../../dishes/dessert/炸鲜奶/炸鲜奶.jpg)

- **预计制作时间**：20 分钟（不含冷却时间）
- **预估烹饪难度**：★★★☆☆

### 必备原料与工具

| 原料/工具 | 说明 |
| :--- | :--- |
| 牛奶 | |
| 玉米淀粉 | |
| 面包糠 | |
| 鸡蛋 | |
| 白糖 | |
| 面包模具 | 或任何浅盘 |

### 计算 (每份约 12 个)

| 原料 | 用量 |
| :--- | :--- |
| 牛奶 | 250g |
| 玉米淀粉 | 30g |
| 面包糠 | 100g |
| 鸡蛋 | 2 个 |
| 白糖 | 30g |

### 操作

1.  在碗中将牛奶、玉米淀粉和白糖搅拌均匀。
2.  在模具内壁刷上一层食用油防粘。
3.  将牛奶混合液倒入锅中，中火烧开后转小火，期间需不停搅拌。
4.  当牛奶液变得粘稠糊状时，立即离火，倒入模具中。
5.  将模具放入冰箱**冷藏 1 小时**，使奶糊凝固。
6.  取出凝固的奶糊，切成大小均匀的长条。
7.  准备两个碗，一个装打散的鸡蛋液，一个装面包糠。
8.  将奶糊条依次裹上蛋液和面包糠。
9.  锅中倒入足量油，加热至五成热（约 150°C）。
10. 下入奶糊条，炸至表面金黄酥脆即可捞出摆盘。

### 附加内容

- **煮奶糊**：必须用小火慢煮并持续搅拌，以防糊底和结块。
- **油温控制**：油温不宜过高或过低，五成热为佳，以保证外皮酥脆而内部不融化。

## 魔芋蛋糕

这是一款专为减脂人群设计的低热量、无麸质甜点，使用魔芋粉和代糖制作，口感独特。

### 操作

1.  烤箱预热至 150℃ (350℉)。
2.  **分离蛋清蛋黄**：操作同[戚风蛋糕](#戚风蛋糕)。

4.  **混合蛋糕糊**：
    *   将分离出的蛋黄加入打发好的蛋白中，用打蛋器低速搅拌均匀。
    *   筛入可可粉和魔芋粉，先用餐刀大致翻拌，再用打蛋器低速搅拌均匀。
5.  **烘烤**：
    *   将蛋糕糊倒入铺好烘焙纸的模具中，抹平表面并轻震几下。
    *   放入预热好的烤箱，烘烤 25 分钟。
6.  **冷却与脱模**：
    *   出炉后倒扣冷却 10 分钟，然后脱模切块。注意防烫。

### 附加内容

- 本食谱的蛋白打发及混合手法可参考[戚风蛋糕](#戚风蛋糕)的制作流程。

## 龟苓膏

龟苓膏是一款传统的中式甜品，口感滑嫩，带有微微的甘苦味，制作非常简单。

![龟苓膏成品](../../../dishes/dessert/龟苓膏/龟苓膏成品.jpg)

- **预计制作时间**：15 分钟（不含冷却时间）
- **预估烹饪难度**：★★☆☆☆

### 必备原料与工具

| 原料/工具 |
| :--- |
| 龟苓膏粉 |
| 冷水 |
| 开水 |
| 白砂糖 |
| 小锅 |
| 搅拌工具 |
| 模具或碗 |

### 计算

| 原料 | 用量 |
| :--- | :--- |
| 龟苓膏粉 | 25 克 |
| 冷水 | 120 毫升 |
| 开水 | 500 毫升 |
| 白砂糖 | 100 克 |

### 操作

1.  在锅中将龟苓膏粉与冷水充分搅拌，直至形成无颗粒的糊状。
2.  在另一个容器中，用开水将白砂糖完全溶解，制成糖水。
3.  将热糖水缓慢冲入龟苓膏糊中，边倒边快速搅拌，防止结块。
4.  将混合液体放回锅中，用中小火加热，并持续搅拌以防粘锅。
5.  加热至液体变粘稠并开始冒小泡时，即可关火。
6.  迅速将液体倒入模具或碗中，自然冷却至凝固。建议冷藏 1-2 小时后食用，口感更佳。

### 附加内容

- **避免移动**：在龟苓膏冷却凝固的过程中，请勿随意移动容器，以免影响成型。
- **搭配建议**：可根据个人口味搭配蜂蜜、炼乳或新鲜水果一同食用。
