## 农家一碗香

农家一碗香是一道地道的湖南菜，主要食材为青椒、鸡蛋和猪肉。此菜咸香下饭，烹饪流程简单，无需特别的食材处理。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★☆☆ |
| **预计备菜时间** | 7 分钟 |
| **预计烹饪时间** | 10 分钟 |
| **预计总计时间** | 17 分钟 |

### 必备原料和工具

*   猪肉（推荐五花肉）：250g
*   青椒：3 个
*   鸡蛋：2 个（打散备用）
*   蒜片：2 片
*   姜片：2 片
*   小米椒：1 个
*   豆瓣酱：10g
*   酱油：15ml
*   白糖：5mg

### 操作步骤

1.  **备菜**：将猪肉切片，肥瘦部分分开放置。青椒和小米辣切段，蒜用刀背拍成末，姜切丝。鸡蛋打入碗中搅散。
2.  **炒鸡蛋**：锅中倒油，开小火加热。油热后倒入蛋液，炒散至断生，盛出备用。
3.  **煸炒猪肉**：锅中视情况补充一点油，开小火。油热后，将肥猪肉片倒入锅中，煸炒至出油。
4.  待肥肉呈金黄色时，转为中火，放入瘦肉片一同翻炒。
5.  **调味**：当瘦肉全部变色后，加入备好的姜丝、蒜末和豆瓣酱，翻炒均匀为猪肉上色。
6.  **混合出锅**：放入青椒、小米椒以及先前炒好的鸡蛋，加入酱油和白糖，继续翻炒至青椒微微断生即可。为保持青椒的清脆口感，不宜久炒。
7.  盛出装盘。

### 附加内容

*   如果在炒鸡蛋步骤中放油较多，后续炒猪肉时可酌情减少或不放油。

## 冬瓜酿肉

![冬瓜酿肉成品](../../../dishes/meat_dish/冬瓜酿肉/冬瓜酿肉成品.jpg)

此菜荤素搭配，口感鲜嫩爽滑，做法简单。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★★☆ |
| **预计总计时间** | 约 30 分钟 |

### 必备原料和工具

*   冬瓜：200g
*   猪肉末：300g
*   鸡蛋：1 个（可选）
*   葱：1 根
*   姜：3-4 片（约 30g）
*   胡椒粉：5g
*   生抽：10ml
*   淀粉：5g
*   水淀粉：淀粉 25g + 水 50ml
*   盐：20g

### 操作步骤

1.  **处理冬瓜**：冬瓜去皮，切成约 25cm 长、3cm 厚的片。将其放入碗中，加入 15g 盐抹匀，腌制 10 分钟使其变软。
    ![腌制好的冬瓜](../../../dishes/meat_dish/冬瓜酿肉/腌制好的冬瓜.jpg)
2.  **调制肉馅**：在腌制冬瓜的同时，另取一碗放入肉末、葱姜末、5g 盐、5g 淀粉、胡椒粉和生抽。用筷子顺时针搅拌约 2 分钟，至食材颜色均匀。
3.  **清洗冬瓜**：将腌制好的冬瓜用清水冲洗三遍，去除多余盐分。
4.  **酿肉**：取一片冬瓜片卷起，将调制好的肉馅塞入其中。
    ![卷肉](../../../dishes/meat_dish/冬瓜酿肉/卷肉.jpg)
5.  **摆盘**：将做好的冬瓜卷沿碟子边缘摆放整齐。可在中间圆圈处打入一个鸡蛋。
    ![摆盘](../../../dishes/meat_dish/冬瓜酿肉/摆盘.jpg)
    ![打鸡蛋](../../../dishes/meat_dish/冬瓜酿肉/打鸡蛋.jpg)
6.  **蒸制**：将摆好盘的冬瓜酿肉放入已烧开水的蒸锅中，盖上锅盖蒸 15 分钟。
7.  **制作芡汁**：取出蒸好的菜品（注意防烫），将碟子里的汤汁倒入锅中，加入水淀粉和 50ml 清水，烧开成芡汁。
8.  **完成**：将芡汁均匀淋在蒸好的冬瓜酿肉上即可。

### 附加内容

*   从蒸锅中取出菜品时，碟子温度很高，请小心操作。

## 凉拌鸡丝

一道快手凉菜，少油低卡，制作简单。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★☆☆ |
| **预计总计时间** | 约 30 分钟 |

### 必备原料和工具

*   鸡胸肉：200 克
*   姜：20 克
*   料酒：20 毫升
*   麻油（或花椒油）：5 毫升
*   生抽：4 毫升
*   香醋：4 毫升
*   白糖：3 克
*   盐：2 克
*   凉白开水

### 操作步骤

1.  **准备**：姜切片备用。
2.  **煮鸡胸肉**：锅中倒入 4 升水，加入鸡胸肉、姜片和料酒。开大火将水烧开，不盖锅盖。
3.  水开后转为中火，用勺子撇去浮沫。
4.  继续煮 5-7 分钟。常温鸡胸肉煮 5 分钟，冷冻鸡胸肉煮 7 分钟。可用筷子插入鸡胸肉，如能轻松插入则代表已熟。
5.  **冷却与撕丝**：将煮熟的鸡胸肉捞出，用凉白开水冲泡降至室温。然后顺着鸡肉纹理将其撕成细丝。
6.  **调制料汁**：取一个碗，加入麻油、生抽、香醋、白糖和盐，搅拌至糖和盐基本溶化。
7.  **拌匀**：将调好的料汁倒入鸡丝中，搅拌均匀即可。

### 附加内容

*   可根据个人口味加入香菜、小葱等调味。嗜辣者可加入辣椒油。

## 卤菜 (以卤牛肉为例)

![卤牛肉](../../../dishes/meat_dish/卤菜/卤牛肉.jpeg)

一道经典的中式卤味料理，肉质鲜嫩，香气四溢。卤水可多次使用，越陈越香。本教程以卤牛肉为例，其他肉类操作流程类似。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★☆☆ |
| **预计总计时间** | 数小时（含浸泡和焖制时间） |

### 必备原料和工具

*   牛腱子：500g
*   卤料包：1 包（约 10g）
*   黄豆酱：15ml
*   豆瓣酱：15ml
*   蚝油：15ml
*   南腐乳：15ml
*   洋葱：半个
*   生姜：30g
*   大蒜：40g
*   干辣椒：10g
*   生抽：120ml
*   老抽：60ml
*   盐：10-15g
*   白糖（推荐黄冰糖）：30g
*   啤酒：1 罐 (330ml)
*   清水：足量
*   高压锅、滤网

### 操作步骤

1.  **预处理牛肉**：牛腱子提前用冷水浸泡 3 小时以上，以去除血水。
2.  **准备卤水**：
    *   **炒糖色**：锅中加入 30g 白糖，小火加热至糖完全融化并呈现棕褐色，加入 150ml 热水搅匀备用。
    *   **准备香料**：洋葱切块，生姜大蒜拍碎，干辣椒掰断。
    *   **熬制卤汤**：锅中加足量水，放入卤料包和准备好的香料，大火烧开。加入黄豆酱、豆瓣酱、蚝油、南腐乳、糖色、生抽、老抽、盐和啤酒，再次烧开。
3.  **卤制牛肉**：
    *   牛腱子放入沸水中焯水 2-3 分钟，捞出用热水冲净浮沫。
    *   将焯好水的牛腱子放入烧开的卤水中，确保卤水没过所有肉。
    *   使用高压锅，上汽后继续烹饪 25-30 分钟。
    *   烹饪完成后，让其在锅中自然冷却并浸泡过夜，以便更加入味。
4.  **冷藏与切片**：将卤好的肉取出，放入冰箱冷藏至定型，然后切片即可食用。

### 附加内容

*   **卤水保存**：每次使用后，将卤水过滤掉固体残渣，重新烧开杀菌，冷却后冷藏或冷冻保存。下次使用时按比例补充调味料。
    ![卤水](../../../dishes/meat_dish/卤菜/卤水.jpeg)
*   **重要提示**：如需卤制素菜，必须另取一部分卤水单独使用，且卤过素菜的卤水不可再重复使用。
*   **凉拌调料参考**：蒜末、葱花、白芝麻、辣椒粉按 1:1:1:1 混合，加入热油、生抽、醋、蚝油、糖和卤汤调制。
*   **其他用途**：卤水可作为牛肉面的汤底，味道极佳。
    ![牛肉面](../../../dishes/meat_dish/卤菜/牛肉面.jpeg)

| **预计总计时间** | 约 45 分钟 |

### 必备原料和工具

*   鸡：半只 (约 500g)
*   辣椒粉：20g
*   花椒：30 颗
*   花生：10 颗
*   小葱：2 颗
*   姜：1 小块
*   蒜：2 瓣
*   白糖：5g
*   生抽：5ml
*   醋：5ml
*   味精：5g
*   花椒粉：5g
*   香菜：5g
*   食用油：20ml
*   冰水

### 操作步骤

1.  **煮鸡**：鸡肉洗净，放入锅中，加清水没过鸡肉。放入姜片、1 颗小葱和 15 颗花椒，大火烧开后转中小火煮 20 分钟。
2.  **冰镇**：取出鸡肉，立即放入冰水中浸泡直至完全冰凉。
3.  **切块**：取出鸡肉，切块后摆盘备用。
4.  **准备配料**：小火烘烤花生至表皮爆裂，去皮切碎。另 1 颗葱切段，蒜拍成末。
5.  **制作红油**：锅内倒油烧热，放入葱段、15 颗花椒和一半蒜末炒香。待油温八成热时关火，滤出热油。将热油冲入放有辣椒粉的碗中，搅拌后滤出红油。
6.  **调制酱汁**：在红油中加入剩余的蒜末、生抽、醋、盐、味精、糖、香油和花椒粉，拌匀放凉。
7.  **完成**：在鸡肉上撒上花生碎，淋上调制好的红油酱汁，最后撒上香菜即可。

## 台式卤肉饭

富含糖和脂肪的台式卤肉饭，每一口都能带来满足感。本做法操作简单，风味不减。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★★★ |
| **预计操作时间** | 30 分钟 |
| **预计炖煮时间** | 60 分钟 |
| **预计总计时间** | 90 分钟 |

### 必备原料和工具

*   带皮五花肉：500g
*   红葱头：25 g
*   大蒜：25 g
*   鸡蛋：4 个（可选）
*   香叶：2 片
*   八角：1 颗
*   冰糖：20 g
*   生抽酱油：75 ml
*   米酒（或料酒）：35 ml
*   白胡椒粉：6 g
*   五香粉：6 g
*   食用油：15 ml
*   米饭

### 操作步骤

1.  **备菜**：带皮五花肉切成约 0.7cm×0.7cm×2.5cm 的细长条。红葱头、大蒜切末。鸡蛋煮熟剥壳，用刀划破蛋白以便入味。
2.  **炒制**：大火热锅，放油滑锅后放入五花肉条，翻炒至肉色变白，淋入 10ml 米酒。继续翻炒至五花肉不再出油。
3.  加入红葱头末，翻炒 1 分钟爆香，再加入蒜末翻炒 30 秒。
4.  **上糖色**：将猪肉推至锅边，放入冰糖加热至融化冒泡成焦糖色，再与猪肉翻拌均匀。
5.  **调味**：加入生抽炒出香气。
6.  **炖煮**：呛入 25 ml 米酒，加水淹过猪肉。加入白胡椒粉、五香粉、八角、香叶和水煮蛋。沸腾后转小火卤 1 小时。期间需每隔 15 分钟搅拌以防粘锅。
7.  **收汁**：1 小时后，开大火收汁，直至酱汁浓稠，呈琥珀色。
8.  **享用**：将卤肉和卤蛋浇在米饭上即可。

### 附加内容

*   **切肉技巧**：未冷冻的五花肉可先放入冷冻室 30 分钟再切，冷冻五花肉可在常温下放置 30 分钟后再切。
*   不同酱油咸度不一，炖煮时请试味调整。

## 牛排

![牛排成品](../../../dishes/meat_dish/牛排/牛排.jpg)

| :--- | :--- |

| **预计总计时间** | 约 15-30 分钟 |

*   黄油：20-25g

*   黑胡椒粉（推荐现磨）：2g
*   平底锅（推荐铸铁锅）

### 操作步骤

![酱牛肉](../../../dishes/meat_dish/酱牛肉/酱牛肉.jpg)

| :--- | :--- |
| **预估烹饪难度** | ★★★★★ |

3.  **炸茄子**：锅中倒宽油，油温七成热时放入茄子炸两分钟，至边缘微黄捞出控油。
4.  **炒肉末**：锅中留底油，倒入肉末炒至颜色变白盛出。
5.  **炒酱**：锅中再倒油，放入豆瓣酱、葱白、姜、蒜炒香，然后倒入肉末翻炒均匀。
6.  **完成**：加入适量清水，倒入炸好的茄子和调好的鱼香汁，爆炒入味收汁。最后放入葱花翻炒均匀即可。

## 麻婆豆腐

![成品](../../../dishes/meat_dish/麻婆豆腐/1.jpeg)
一道家常下饭菜，富含多种微量元素。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★☆☆ |
| **预计总计时间** | 约 20 分钟 |

### 必备原料和工具

*   内脂豆腐：1 盒
*   五花肉：20-30g
*   咸鸭蛋：1 枚（灵魂）
*   香料：大蒜、生姜、小米椒、花椒
*   酱料：香辣酱、酱油
*   食盐

### 操作步骤

1.  **备料**：大蒜和生姜切碎，小米辣切圈，五花肉切成肉糜。
2.  **腌制肉糜**：肉糜中加入一半的食盐和酱油，搅拌均匀。
3.  **处理咸鸭蛋**：咸鸭蛋对半切开，只取蛋白，捣碎备用。
4.  **处理豆腐**：用刀在盒中将内脂豆腐划成小块。
5.  **炒料**：热锅倒油，小火放入大蒜、生姜、辣椒圈、花椒、咸蛋蛋白碎、香辣酱翻炒出香味。
6.  **炒肉**：调成中火，放入肉糜翻炒至变色。
7.  **煮豆腐**：调成小火，放入豆腐块，均匀撒上剩余的食盐和酱油。从锅边倒入开水没过豆腐。
8.  **完成**：开大火，水沸后转中火煮约 10 分钟，待汤汁收浓、豆腐入色后关火盛盘。

## 黑椒牛柳

![黑椒牛柳成品](../../../dishes/meat_dish/黑椒牛柳/黑椒牛柳.jpg)
一道简单易做的菜，蔬菜与肉类均衡，富含蛋白质。

| 项目 | 详情 |
| :--- | :--- |
| **预估烹饪难度** | ★★★★☆ |
| **预计总计时间** | 约 60 分钟（含腌制时间） |

### 必备原料和工具

*   牛肉（牛里脊或牛排肉）：按需
*   洋葱：适量
*   菜椒（红/黄椒）：适量
*   腌料：黑椒腌料、淀粉、黑胡椒粉
*   调味料：盐、花生油

### 操作步骤

1.  **切肉**：将牛肉切成条状。
2.  **腌制**：使用黑椒腌料腌制牛肉，时间参照商品说明。结束前可加入黑胡椒粉和淀粉，混合均匀后静置 20 分钟。
3.  **炒制**：开火热锅，加入花生油。油热后放入牛肉，中大火翻炒 2 分钟至牛肉外表变色。
4.  **加入配菜**：放入切好的洋葱和菜椒，翻炒 2 分钟。
5.  **调味**：加入盐，再次撒入黑胡椒粉，翻炒 30 秒，搅拌均匀。
6.  **完成**：观察到洋葱变软即可关火出锅。
