# 汤与粥

本部分汇集了多款暖心暖胃的汤品与粥类食谱。无论是寻求滋补的养生汤，还是简单快手的家常粥，您都可以在这里找到详尽的制作指南，为自己和家人带来一份温暖与健康。

| 菜品 | 主要食材 | 预估烹饪难度 | 简介 |

| 米粥 | 大米 | ★★ | 基础家常粥，具有补脾、和胃、清肺的功效。 |
